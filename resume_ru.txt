Rental Management SaaS — Пет-проект
Веб-приложение для управления арендой недвижимости
Развёрнуто на сервере: managerrent.com

• RESTful backend-сервис на Java 17 и Spring Boot 3.5 с архитектурой MVC
• JWT-авторизация с ролевой моделью доступа и Spring Security
• модель данных с 7+ сущностями (пользователи, апартаменты, адреса, бронирования, гости) и связями между ними

• Redis для организации очередей email-уведомлений
• Docker Compose для запуска приложения и базы данных в контейнерах
