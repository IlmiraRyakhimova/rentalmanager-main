# Rental Manager - Frontend

Современный фронтенд для системы управления арендой недвижимости.

## 🚀 Технологии

- **Vue 3** - прогрессивный JavaScript фреймворк
- **Vue Router** - официальный роутер для Vue.js
- **Pinia** - современное state management решение для Vue
- **Axios** - HTTP клиент для работы с API
- **Vite** - быстрый инструмент сборки

## 📋 Возможности

- ✅ Регистрация агентов с валидацией
- ✅ Вход в систему с JWT токенами
- ✅ Автоматическое обновление токенов
- ✅ Защищенные маршруты
- ✅ Современный UI/UX дизайн
- ✅ Адаптивная верстка
- ✅ Индикатор силы пароля

## 🛠️ Установка и запуск

### Предварительные требования

- Node.js >= 20.19.0 или >= 22.12.0
- npm

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173

### Сборка для продакшена

```bash
npm run build
```

### Предварительный просмотр production сборки

```bash
npm run preview
```

## ⚙️ Конфигурация


## 🔐 Аутентификация

### Процесс регистрации

1. Пользователь заполняет форму регистрации
2. Данные отправляются на `/api/auth/sign-up`
3. При успехе получаются JWT токены
4. Токены сохраняются в localStorage
5. Редирект на `/dashboard`

### Процесс входа

1. Пользователь вводит email и пароль
2. Данные отправляются на `/api/auth/sign-in`
3. При успехе получаются JWT токены
4. Токены сохраняются в localStorage
5. Редирект на `/dashboard`

### Автообновление токенов

Axios интерцептор автоматически:
- Добавляет Access Token ко всем запросам
- При получении 401 ошибки обновляет токен
- Повторяет неудавшийся запрос с новым токеном

## 🛣️ Маршруты

- `/` - Главная страница (только для неавторизованных)
- `/login` - Вход (только для неавторизованных)
- `/register` - Регистрация (только для неавторизованных)
- `/dashboard` - Dashboard (требует авторизации)

## 📝 Валидация форм

### Регистрация

- **Имя**: минимум 2 символа
- **Email**: валидный email формат
- **Телефон**: 10-15 цифр, может начинаться с +
- **Пароль**: 8-72 символа
- **Подтверждение пароля**: должно совпадать с паролем

### Вход

- **Email**: валидный email формат
- **Пароль**: обязательное поле

## 🔧 API интеграция

Приложение интегрируется с бэкендом через следующие эндпоинты:

- `POST /api/auth/sign-up` - Регистрация
- `POST /api/auth/sign-in` - Вход
- `POST /api/auth/refresh-token` - Обновление токена
- `POST /api/auth/log-out` - Выход
