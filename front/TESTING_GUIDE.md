# 📱 Тестирование Rental Manager Frontend

## 🌐 Открыть приложение

**URL**: http://localhost:5173

## 🎯 Сценарий тестирования

### Шаг 1: Главная страница
✅ Вы увидите:
- Заголовок "RENTAL MANAGER"
- Описание "Ваш персональный менеджер аренды"
- Две кнопки: "Зарегистрироваться" и "Войти как агент"
- Три карточки с возможностями системы

### Шаг 2: Регистрация (⭐ главная фича)
Нажмите "Зарегистрироваться"

**Что протестировать:**

1. **Валидация имени**
   - Попробуйте ввести 1 символ → увидите ошибку
   - Введите "Иван Петров" → ошибка исчезнет

2. **Валидация email**
   - Введите "test" → ошибка "Введите корректный email"
   - Введите "ivan@agent.com" → ОК

3. **Валидация телефона**
   - Введите "123" → ошибка
   - Введите "+79991234567" → ОК

4. **Индикатор силы пароля** 🌟
   - Введите "test" → красная полоска (слабый)
   - Введите "Test1234" → желтая полоска (средний)
   - Введите "Test1234!@#" → зеленая полоска (сильный)

5. **Показ/скрытие пароля**
   - Нажмите 👁️ справа от поля пароля
   - Пароль станет видимым/невидимым

6. **Подтверждение пароля**
   - Введите другой пароль → ошибка "Пароли не совпадают"
   - Введите тот же пароль → ОК

7. **Кнопка отправки**
   - Если есть ошибки → кнопка неактивна
   - Все поля заполнены корректно → кнопка активна

**Рекомендуемые данные для теста:**
```
Имя: Иван Петров
Email: ivan@agent.com
Телефон: +79991234567
Пароль: TestPass123
Подтверждение: TestPass123
```

8. **Нажмите "Зарегистрироваться"**
   - Появится spinner
   - При успехе → переход на Dashboard
   - При ошибке → сообщение об ошибке

### Шаг 3: Dashboard
✅ Вы увидите:
- Приветствие "Добро пожаловать, Иван Петров!"
- Ваше имя в header
- 4 карточки (Квартиры, Бронирования, Клиенты, Отчеты)
- Кнопку "Выйти"

**Протестируйте:**
- Наведите на карточки → они поднимаются
- Нажмите "Выйти" → вернетесь на главную

### Шаг 4: Вход
На главной странице нажмите "Войти как агент"

**Протестируйте:**

1. **Неверные данные**
   - Email: test@test.com
   - Пароль: wrongpass
   - Нажмите "Войти" → ошибка "Неверный email или пароль"

2. **Правильные данные**
   - Email: ivan@agent.com
   - Пароль: TestPass123
   - Нажмите "Войти" → переход на Dashboard

## 🐛 Что может пойти не так

### Backend не запущен
Если увидите ошибку при регистрации/входе:
```
Произошла ошибка. Попробуйте позже.
```

Решение:
1. Проверьте что backend запущен на порту 8080
2. Проверьте `.env` файл: `VITE_API_URL=http://localhost:8080`

### CORS ошибка
Откройте Console в DevTools (F12)
Если видите ошибку CORS → настройте CORS в backend
