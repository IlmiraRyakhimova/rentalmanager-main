# 🎨 Rental Manager Frontend - Краткое резюме

## ✅ Что создано

### Основные компоненты
1. **Страница регистрации** (`/register`) - главный акцент ⭐
2. **Страница входа** (`/login`)
3. **Главная страница** (`/`)
4. **Dashboard** (`/dashboard`)

### Технический стек
- Vue 3 (Composition API)
- Vue Router (защищенные маршруты)
- Pinia (state management)
- Axios (HTTP клиент с интерцепторами)
- Vite (сборщик)

### Особенности дизайна
- 🎨 Современный градиентный дизайн (фиолетовый)
- 📱 Полностью адаптивная верстка
- ✨ Плавные анимации и переходы
- 🎯 Интуитивный UX

## 🌟 Страница регистрации - детали

### Валидация полей
- **Имя**: мин. 2 символа
- **Email**: валидный формат
- **Телефон**: +79991234567 (10-15 цифр)
- **Пароль**: 8-72 символа
- **Подтверждение**: совпадение паролей

### Фичи
✅ Индикатор силы пароля (с градиентом)
✅ Показ/скрытие пароля
✅ Валидация в реальном времени
✅ Красивые сообщения об ошибках
✅ Spinner при загрузке
✅ Блокировка кнопки при невалидной форме

## 🚀 Быстрый старт

```bash
cd front
npm install
npm run dev
```

Откройте http://localhost:5173

## 🔐 Авторизация

### Регистрация
- Роль: `AGENT` (зафиксирована)
- После регистрации → автоматический вход
- Переход на `/dashboard`

### JWT токены
- Access Token + Refresh Token
- Автоматическое обновление при 401
- Хранение в localStorage

### Защита маршрутов
- `/dashboard` - требует авторизации
- `/login`, `/register` - только для гостей

## 📁 Структура

```
front/src/

```

## 🎯 API интеграция

### Эндпоинты
```
POST /api/auth/sign-up      # Регистрация
POST /api/auth/sign-in      # Вход
POST /api/auth/refresh-token # Обновление токена
POST /api/auth/log-out      # Выход
```

### Конфигурация
Файл `.env`:
```
VITE_API_URL=http://localhost:8080
```
