## 🔧 Скрипты (4 файла)

### 1. **deploy.sh** - Основной скрипт деплоя
   ```bash
   ./deploy.sh
   ```
   - Останавливает контейнеры
   - Пересобирает образы
   - Запускает обновленные контейнеры
   - Проверяет состояние
   - **Сохраняет данные БД**

### 2. **status.sh** - Проверка состояния
   ```bash
   ./status.sh
   ```
   - Статус всех контейнеров
   - Использование ресурсов
   - Docker volumes
   - Открытые порты
   - Доступность сервисов

### 3. **logs.sh** - Просмотр логов
   ```bash
   ./logs.sh [backend|frontend|db|redis|all]
   ```
   - Логи конкретного сервиса
   - Или всех сервисов сразу
   - Режим follow (обновление в реальном времени)

### 4. **backup-db.sh** - Бэкап базы данных
   ```bash
   ./backup-db.sh
   ```
   - Создает дамп PostgreSQL
   - Сохраняет с временной меткой
   - Удаляет старые бэкапы (>7 дней)
   - Показывает инструкцию по восстановлению
