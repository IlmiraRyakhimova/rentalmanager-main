# ✅ Что было настроено для автоматического деплоя

## 📦 Созданные файлы

### 1. GitHub Actions Workflow
- **Файл:** `.github/workflows/deploy.yml`
- **Функция:** Автоматический деплой при push в ветку `deploy`
- **Что делает:**
  - Подключается к серверу по SSH
  - Скачивает последние изменения из ветки `deploy`
  - Запускает скрипт деплоя

### 2. Скрипт деплоя
- **Файл:** `deploy.sh`
- **Функция:** Безопасное обновление приложения
- **Что делает:**
  - Останавливает контейнеры
  - Пересобирает Docker образы
  - Запускает обновленные контейнеры
  - **Сохраняет данные БД** (важно!)

### 3. Скрипт бэкапа БД
- **Файл:** `backup-db.sh`
- **Функция:** Создание резервных копий базы данных
- **Что делает:**
  - Создает дамп PostgreSQL
  - Сохраняет с меткой времени
  - Удаляет старые бэкапы (>7 дней)

### 4. Скрипт просмотра логов
- **Файл:** `logs.sh`
- **Функция:** Удобный просмотр логов сервисов
- **Использование:**
  - `./logs.sh` - все логи
  - `./logs.sh backend` - только backend
  - `./logs.sh frontend` - только frontend
  - `./logs.sh db` - только база данных

### 5. Скрипт проверки состояния
- **Файл:** `status.sh`
- **Функция:** Мониторинг всех сервисов
- **Показывает:**
  - Статус контейнеров
  - Использование ресурсов
  - Docker volumes
  - Доступность сервисов

### 6. Пример переменных окружения
- **Файл:** `.env.example`
- **Функция:** Шаблон для создания `.env` на сервере

## 🔐 Защита базы данных

### Как это работает:

1. **Docker volumes** используются для хранения данных:
   - `postgres-data` - данные PostgreSQL
   - `redis-data` - данные Redis

2. **Команда `docker-compose down`:**
   - ✅ Останавливает и удаляет контейнеры
   - ✅ **НЕ** удаляет volumes с данными
   - ✅ Данные БД остаются в сохранности

3. **Что нужно для удаления данных (НЕ ДЕЛАЙТЕ!):**
   - `docker-compose down -v` - удалит volumes
   - `docker volume rm rentalmanager-main_postgres-data` - удалит конкретный volume

### Проверка в docker-compose.yml:

```yaml
services:
  postgres-db:
    volumes:
      - postgres-data:/var/lib/postgresql/data  # ✅ Volume для данных

volumes:
  postgres-data:  # ✅ Определение volume
  redis-data:     # ✅ Volume для Redis
```
